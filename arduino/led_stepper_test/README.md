# 단색 LED 스트립 + 28BYJ-48 스텝 모터 테스트

라이브러리 필요 없음. `AUTO_RUN 1`(기본)이면 전원을 켜자마자 LED 밝기 1 + 모터 연속 회전(1 RPM)이 시작됩니다.
업로드 후 시리얼 모니터 **115200 baud / LF** → `t` 입력 시 자동 테스트.

## 배선 (Uno 기준)

| 부품 | 핀 |
|---|---|
| MOSFET 보드 SIG(게이트) | D6 (PWM 핀) |
| ULN2003 IN1~IN4 | D9 / D10 / D11 / D3 (마이크로스텝, 기본) |
| ULN2003 IN1~IN4 | D2 / D3 / D4 / D5 (`MICROSTEPS 0` 하프스텝) |
| ULN2003 + / − | 5V / GND |

- **GND 공통**: LED 스트립 전원(12V 등), 모터 전원, 아두이노 GND 연결
- 모터가 안 돌면 `q`(코일 점검)로 ULN2003 보드 LED A~D 가 순서대로 켜지는지 확인

## 마이크로스텝

`MICROSTEPS`(기본 16)로 풀스텝을 나눕니다. 코일 전류를 PWM 으로 조절해야 해서 IN1~IN4 는 PWM 핀
D9, D10, D11, D3 이어야 하며, 소음을 없애려고 Timer1/Timer2 PWM 주파수를 31kHz 로 올립니다.
1바퀴 = 2048 × MICROSTEPS 스텝 (16 → 32768).

## 시리얼 명령
| 명령 | 동작 |
|---|---|
| `t` | 자동 테스트 |
| `n` / `o` | LED 켜기 / 끄기 |
| `L 128` | LED 밝기 (0–255) |
| `a`, `a 500` | 숨쉬기: 1→50→100→150→200→250→…→1 단계별 (유지시간 ms, 기본 1000) |
| `k` | 깜빡이기 |
| `f`, `f 180` | 불꽃 일렁임 (최대 밝기) |
| `g` / `G` | 모터 계속 회전 정방향 / 역방향 (`x` 로 정지) |
| `q` | 코일 배선 점검 |
| `m 512`, `m -512` | 지정 스텝 이동 |
| `R 1`, `R -1` | N바퀴 회전 |
| `v 1`, `v 0.5` | 속도 RPM (기본 1 RPM) |
| `s 300` | 속도 (steps/sec) |
| `x` | 모터 정지 + 전원 해제 |
| `p` | 상태 출력 |
