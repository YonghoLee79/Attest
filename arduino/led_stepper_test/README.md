# LED 스트립 + 스텝 모터 테스트

## 준비
1. Arduino IDE → 라이브러리 매니저 → **Adafruit NeoPixel** 설치
2. `led_stepper_test.ino` 상단 **설정** 부분을 배선에 맞게 수정
   - `NUM_LEDS`, `LED_PIN`
   - `STEPPER_DRIVER` : `DRIVER_STEP_DIR`(A4988/DRV8825/TMC) 또는 `DRIVER_ULN2003`(28BYJ-48)
3. 업로드 후 시리얼 모니터 **115200 baud / Newline** → `t` 입력 시 자동 테스트

## 기본 배선 (Uno 기준)

| 부품 | 핀 |
|---|---|
| LED 스트립 DIN | D6 (330Ω 직렬 저항 권장) |
| A4988 STEP / DIR / EN | D3 / D4 / D5 |
| ULN2003 IN1~IN4 | D8 / D9 / D10 / D11 |

## 주의
- **GND 공통**: LED 전원, 모터 전원, 아두이노 GND를 반드시 연결
- WS2812B는 LED당 최대 약 60mA → 30개 흰색 최대 밝기 ≈ 1.8A. USB 전원으론 부족하니 밝기를 낮게 두거나 5V 외부 전원 사용
- A4988/DRV8825: VMOT에 100µF 이상 커패시터, 전류 제한(Vref) 먼저 설정. 모터가 연결된 상태로 전원이 켜져 있을 때 모터 선을 뽑지 말 것
- 모터가 떨기만 하고 안 돌면 속도를 낮추기(`s 200`) 또는 코일 결선 확인

## 시리얼 명령
| 명령 | 동작 |
|---|---|
| `t` | 자동 테스트 (색상 → 픽셀 하나씩 → 모터 정/역 1바퀴 → 동시 동작) |
| `r` `g` `b` `w` `o` | 빨강/초록/파랑/흰색/끄기 |
| `a` `c` `k` | 무지개 / 체이스 / 픽셀 하나씩 이동 |
| `B 100` | 밝기 (0–255) |
| `m 200`, `m -200` | 지정 스텝 이동 |
| `R 2`, `R -1` | N바퀴 회전 |
| `s 300` | 속도 (steps/sec) |
| `x` | 모터 정지 + 전원 해제 |
| `p` | 상태 출력 |
