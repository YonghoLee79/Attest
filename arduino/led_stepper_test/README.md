# 단색 LED 스트립 + 28BYJ-48 스텝 모터 테스트

라이브러리 필요 없음. 업로드 후 시리얼 모니터 **115200 baud / LF** → `t` 입력 시 자동 테스트.

## 배선 (Uno 기준)

| 부품 | 핀 |
|---|---|
| MOSFET 보드 SIG(게이트) | D6 (PWM 핀) |
| ULN2003 IN1~IN4 | D2 / D3 / D4 / D5 |
| ULN2003 + / − | 5V / GND |

- **GND 공통**: LED 스트립 전원(12V 등), 모터 전원, 아두이노 GND 연결
- 모터가 안 돌면 `q`(코일 점검)로 ULN2003 보드 LED A~D 가 순서대로 켜지는지 확인

## 시리얼 명령
| 명령 | 동작 |
|---|---|
| `t` | 자동 테스트 |
| `n` / `o` | LED 켜기 / 끄기 |
| `L 128` | LED 밝기 (0–255) |
| `a` / `k` | 숨쉬기 / 깜빡이기 |
| `q` | 코일 배선 점검 |
| `m 512`, `m -512` | 지정 스텝 이동 |
| `R 1`, `R -1` | N바퀴 회전 |
| `s 300` | 속도 (steps/sec) |
| `x` | 모터 정지 + 전원 해제 |
| `p` | 상태 출력 |
